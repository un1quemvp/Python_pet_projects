# Python Console Mini-Projects

A collection of console mini-projects completed during the [Generation Python: Course for Beginners](https://stepik.org/course/58852) on Stepik.

The repository focuses on practicing core Python syntax, input validation, and decomposing logic into functions using only the standard library.

## Projects

| Project | Directory | Description |
| :--- | :--- | :--- |
| **Caesar Cipher** | [`caesar_cipher/`](./caesar_cipher) | Encrypts and decrypts text for English and Russian alphabets with custom shift keys while preserving case and punctuation. |
| **Magic 8 Ball** | [`random_icosahedron/`](./random_icosahedron) | Console fortune-telling script simulating a 20-sided Magic 8 Ball die using the `random` module and input loops. |
| **Number Guessing Game** | [`random_num/`](./random_num) | Interactive CLI game with configurable number bounds, attempt counter, and user input validation. |
| **Secure Password Generator** | [`security_passwords/`](./security_passwords) | Generates customizable passwords based on length and selected character sets (digits, uppercase/lowercase letters, punctuation, and ambiguous character filtering). |

## Concepts Practiced
- Control flow, loops, and functions
- String manipulation and ASCII character codes
- User input validation and edge-case handling
- Python Standard Library (`random`)
